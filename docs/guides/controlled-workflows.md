# Controlled workflows

Navigation and forms use the same child, reducer and effect lifecycle as other application features.

`updateTuiNavigation(stack, transition, child.remove, outputs?)` applies the existing navigation stack transition. An entry stores `{ child, focus? }` in its `state`. Pushing a screen leaves earlier child lifetimes mounted; render only the active screen, or retain hidden screen elements through the existing components. Replacing, popping or resetting cancels every removed child lifetime. Store the desired parent-scope focus selector (resolve child-local IDs with `child.elementId(instance, localId)`) in the retained screen before opening a modal; revealing it returns that focus request. Modal domain results can be passed as `outputs`; the parent decides what they mean. Keep child subscriptions for every retained screen if hidden work should continue. Generations must be fresh when remounting a removed child.

`createTuiForm()` owns controlled values, an accepted baseline, touched fields, field errors and ordinary prepared-query states. Values are immutable application-owned snapshots. `change` cancels validation and submission and rejects their stale completions. `validate` runs pure validation and optional asynchronous validation; `submit` validates before invoking the application submission effect. Repeated submissions while pending are no-ops. A successful current submission accepts the submitted values as the baseline. Editing back to the baseline clears the dirty decision. Field equality is shallow identity, so applications should use stable immutable field values.

Validation rules and submission operations remain application code. Work is cancellable through the existing effect context; external side effects already performed by an operation cannot be undone by cancellation. The parent may display pending/error/result state as appropriate. Put a form inside `createTuiChild` to gain child-lifetime cancellation; `examples/tui/features/profile-form.ts` and `profile-navigation.ts` demonstrate editing, asynchronous validation, submission and a typed domain output without extra request revisions or runtime managers.
